# Подготовка правил для .NET

Формулируй каждое правило так, чтобы им можно было воспользоваться в новом проекте. Выдели решение из исходного кода и покажи небольшой самостоятельный шаблон с нейтральными именами. Укажи, какие типы или настройки предоставляет проект и какой результат должен получить читатель.

Ссылки внутри навыка ведут к его материалам или к документации используемого инструмента. Внутренние адреса, пути к исходникам, ветки и ревизии проектов-образцов в публикуемые материалы не включаются.

В общий навык переноси решения, которые можно применить в другом проекте команды. Предметные ограничения и состав полей конкретного API фиксируй в самом проекте. Если область действия договорённости неясна, уточни её у автора до публикации.
